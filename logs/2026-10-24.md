## 💡 Concept of the Day

### ACID Transactions — the four promises your database keeps

A transaction is a group of database operations treated as one unit: either all of them happen, or none of them do. The classic bank transfer (debit one account, credit another) is the textbook example — a half-finished transfer would be worse than no transfer at all.

ACID is the checklist a reliable database promises for each transaction:

- **Atomicity** — all or nothing. If any step fails, the whole transaction rolls back, leaving the data exactly as it was before.
- **Consistency** — valid state to valid state. A transaction must respect the database rules (constraints, foreign keys, unique indexes); anything that would break them is rejected.
- **Isolation** — concurrent transactions do not trip over each other. One transaction's unfinished work stays invisible to others, so two users updating the same row cannot produce a garbled result.
- **Durability** — once a transaction commits, it stays committed, even if the server crashes a second later. Databases usually achieve this with a write-ahead log on persistent storage.

The trade-off to remember: stronger isolation costs performance, so databases offer isolation levels (from Read Uncommitted up to Serializable) that let you choose how much safety you need. Reach for strict guarantees where money or inventory is involved; relax them where a slightly stale read is harmless.

## 🛠️ Tool of the Day

### jq — slice and reshape JSON from the terminal

`jq` is a lightweight command-line JSON processor, often described as `sed` for JSON. It reads JSON from a file or stdin, applies a small filter expression, and prints the transformed result — perfect for digging through API responses without opening an editor.

Why it is useful:

- Pull one field out of a huge API response: `curl -s https://api.example.com/users | jq '.[0].name'`
- Filter and reshape in one pass: `jq '.[] | select(.active) | {name, email}'`
- Get raw strings for shell scripts with `-r`, or compact output with `-c`

How to try it:

```bash
sudo apt install jq        # Debian/Ubuntu
brew install jq            # macOS
echo '{"name": "Luna", "role": "agent"}' | jq '.name'
```

Once you can pipe API output through `jq`, debugging endpoints and writing shell scripts around JSON becomes dramatically faster.
