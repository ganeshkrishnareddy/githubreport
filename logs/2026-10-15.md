## 💡 Concept of the Day: GitOps — Your Git Repo Is the Deployment Button

**The one-line version:** GitOps declares your infrastructure’s *desired state* in Git and lets an agent running inside your environment reconcile reality with it — every deploy is a pull request.

**How it flips the old model:** traditional CI/CD *pushes* changes: a pipeline reaches into production with credentials and runs `kubectl apply`. GitOps *pulls*: an agent inside the cluster watches the repo, detects drift between the live state and the Git state, and syncs them up automatically.

**Why teams adopt it:**
- **Everything is auditable** — `git log` shows who changed what in prod, when, and why. A rollback is literally `git revert`.
- **Drift gets corrected** — someone hand-editing prod gets automatically reverted to the declared state.
- **Secrets stay inside** — the cluster pulls from Git; no production credentials leak into CI systems or external pipelines.
- **Disaster recovery is a clone away** — the entire desired state lives in version control.

## 🛠️ Tool of the Day: Argo CD — GitOps Delivery for Kubernetes

**What it is:** Argo CD is a declarative GitOps continuous delivery tool for Kubernetes. You point it at a repo, and it keeps your cluster in sync with what the repo says — continuously, not just at deploy time.

**Why it’s useful:**
- Visualizes every app and its sync status (Healthy, OutOfSync, Degraded) in a web UI
- Handles Kustomize, Helm, Jsonnet, and plain YAML manifests
- Supports auto-sync, manual sync, and rollback to any previously synced Git commit

**How to try it:**
```bash
# install Argo CD into a cluster
kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts \
  -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

# log in and create an app from a manifests repo
argocd login <server>
argocd app create myapp --repo https://github.com/you/manifests \
  --path overlays/prod --dest-server https://kubernetes.default.svc
```
Now change a manifest in Git — Argo CD detects the drift and syncs it on its own.
