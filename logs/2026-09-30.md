# 📝 Daily Log — 30 September 2026

## 💡 Concept of the Day: Supply-Chain Attacks

**The one-line version:** Instead of breaking into your app, attackers poison the trusted software you build on — a library, a build tool, an update mechanism. If you can't beat the lock, compromise the locksmith.

**How it works:**
- **Typosquatting** — publishing `requets` instead of `requests` and waiting for a typo.
- **Dependency confusion** — registering a public package with the same name as a company's private one, so installers grab the malicious public copy.
- **Maintainer takeover** — the long game: earn trust in an open-source project, gain commit access, then ship a backdoor.

**Why it matters:** A typical app pulls in hundreds of transitive dependencies. One poisoned package can reach thousands of downstream projects — and perimeter defenses never see it coming.

**Real-world note:** The XZ Utils backdoor (CVE-2024-3094, CVSS 10.0). An attacker using the name "Jia Tan" spent roughly two years contributing to the xz compression library, became a co-maintainer, and shipped a backdoor in the 5.6.0/5.6.1 release tarballs that could hijack SSH authentication on affected Linux systems. It was caught only because engineer Andres Freund noticed SSH logins getting slightly slower.

**Defend yourself:** Pin versions, commit lockfiles, audit what you install, and prefer actively maintained packages.

## 🛠️ Tool of the Day: uv

- **What:** `uv` — "an extremely fast Python package and project manager, written in Rust" by Astral (the team behind Ruff). One tool replacing `pip`, `pip-tools`, `pipx`, `poetry`, `pyenv`, `twine`, and `virtualenv`.
- **Why it's useful:** It resolves and installs dependencies dramatically faster than pip, and its universal lockfile (`uv.lock`) records the exact version of every dependency — making your dependency tree reproducible and auditable, a small but real defense against supply-chain drift.
- **Try it:** Install with `curl -LsSf https://astral.sh/uv/install.sh | sh`, then:

```
uv init demo && cd demo
uv add requests
uv run main.py
```

It can also install and manage Python versions (`uv python install 3.12`) and run tools ephemerally without installing them (`uvx ruff check`).
