## 💡 Concept of the Day

### CAP Theorem — you can't have all three (at once)

When data lives on more than one machine, the CAP theorem says a distributed data store can guarantee at most two of these three properties during a network partition:

- **Consistency (C)** — every read gets the most recent write, or an error. All nodes agree on the current state.
- **Availability (A)** — every request gets a (non-error) response, even if the data might be stale.
- **Partition Tolerance (P)** — the system keeps running even when nodes can't talk to each other.

The catch most explanations skip: partitions are not optional. Networks fail, so any real distributed system must tolerate them. The practical choice is therefore not "pick any two" — it is **CP or AP when a partition happens**:

- **CP** — refuse or block rather than serve stale data. Pick this when being wrong is worse than being unavailable: bank balances, inventory counts, leader election.
- **AP** — keep answering, possibly with slightly out-of-date data, and reconcile later. Pick this when staying up matters more than perfect freshness: social feeds, shopping carts, sensor dashboards.

When there is no partition, a well-built system can deliver all three. CAP only bites at the moment the network splits — so ask any database, "what do you do when the network splits?" before you ask which two letters it claims.

## 🛠️ Tool of the Day

### uv — one fast tool for Python projects

`uv`, by Astral (the team behind Ruff), is a Python package and project manager written in Rust. It replaces the usual pile of tools — pip, pip-tools, pipx, Poetry, pyenv, virtualenv — with a single binary, and it is dramatically faster than pip at resolving and installing packages.

How to try it:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv init my-project
cd my-project
uv add requests
uv run python main.py
```

Why it is useful: `uv init` scaffolds a project, `uv add` updates `pyproject.toml` and a lockfile (`uv.lock`) you can commit for reproducible installs, `uv run` handles the virtual environment for you, and `uv python install` can fetch Python itself. If you only want a speed boost on an existing workflow, `uv pip` is a pip-compatible interface that drops into scripts you already have.
