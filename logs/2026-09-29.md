# 📝 Daily Log — 29 September 2026

## 💡 Concept of the Day: MCP (Model Context Protocol)

**The one-line version:** MCP is a standard way for AI assistants to connect to external tools and data — think of it as "USB-C for AI integrations."

**How it works:**
- **Host** — the AI app you use (e.g. Claude Desktop, VS Code)
- **Client** — lives inside the host and speaks the MCP protocol
- **Server** — exposes *tools*, *resources*, and *prompts* (e.g. GitHub's official MCP server exposes repo search, file reads, and PR management)

**Why it matters:** Before MCP, every AI × tool integration was custom-built. Now one open protocol covers them all — the same assistant can talk to GitHub, Postgres, Slack, or your local filesystem through interchangeable MCP servers.

**Real-world note:** This very repo's daily automation runs through GitHub's official MCP server — no custom GitHub integration code needed.

## 🛠️ Tool of the Day: GitHub's Official MCP Server

- **What:** `github/github-mcp-server` — gives any MCP-compatible AI assistant structured access to GitHub (repos, issues, PRs, code search).
- **Why it's useful:** Your AI assistant can review PRs, search code, and triage issues without you copy-pasting anything into chat.
- **Try it:** In Claude Desktop or any MCP client, add the GitHub MCP server with a personal access token, then ask it to "summarize the open PRs in my repo."
