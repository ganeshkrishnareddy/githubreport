## 💡 Concept of the Day

### Idempotency — make API retries safe

Networks fail halfway: your client sends "charge ₹500", the server processes it, and the response gets lost on the way back. Did the charge go through? If the client retries blindly, the customer may be charged twice.

An operation is **idempotent** when repeating it has the same effect as doing it once. `GET`, `PUT`, and `DELETE` are idempotent by design in HTTP — send them ten times and the end state is the same. `POST` is not: each call can create a new resource or charge a card again.

The fix for `POST` is an **idempotency key**: a unique value (usually a UUID) the client generates and sends in a header such as `Idempotency-Key`. The server stores the key with the result of the first request. If a retry arrives with the same key, the server returns the stored result instead of running the operation again.

Rules of thumb:

- Generate the key on the client, once per logical operation — not per attempt — and keep it stable across retries.
- Store the key with the result, and expire it after a sensible window (e.g. 24 hours) so stale keys do not pile up.
- Scope keys per endpoint and per user; the same key must not accidentally match a different operation.

Idempotency turns "did it go through?" from a bug hunt into a non-issue — your retries become safe by construction.

## 🛠️ Tool of the Day

### Bruno — the open-source API client that stores collections as files

Postman is powerful, but its collections live in the cloud and its free tier keeps changing. **Bruno** is a fast, open-source API client that stores every request as a plain-text file in a folder you control — so you can commit your API collections to Git, review them in pull requests, and share them without an account.

Why it is worth trying:

- **Git-friendly.** Collections are files, so your API requests version alongside your code.
- **No account needed.** Everything runs locally; nothing is forced into a cloud workspace.
- **Scriptable.** Write pre-request and post-response scripts in JavaScript, set variables from responses, and chain requests together.

How to try it:

```bash
# macOS
brew install bruno
# or download the desktop app from usebruno.com
```

Open Bruno, create a collection, and add a request with an `Idempotency-Key` header to see how your API handles retries — a quick way to test today’s concept hands-on.
