## 💡 Concept of the Day: The Event Loop

**The one-line version:** JavaScript runs on a single thread, yet it juggles timers, network requests, and UI events without freezing — the event loop is the scheduler that makes that possible, running one piece of code at a time and queueing everything else until its turn comes.

**How it works:**
- Three moving parts: the **call stack** (what is running right now), the **task queue** (macrotasks like `setTimeout`, click handlers, and completed I/O), and the **microtask queue** (promise callbacks and `queueMicrotask`).
- Each turn of the loop runs the oldest task to completion, then **drains the entire microtask queue** (even microtasks scheduled by other microtasks), and only then hands control back for rendering.
- This is why `Promise.resolve().then(...)` always runs before `setTimeout(..., 0)`: microtasks cut ahead of the next macrotask.

**Why it matters:** With only one thread, any synchronous function that runs long blocks *everything* — no clicks, no timers, no network callbacks. "Blocking the event loop" is the root cause of most mysterious Node.js and browser slowness, and profilers literally measure event-loop delay to spot it.

**Try the classic quiz:** predict the order, then run it:
```js
console.log("1");
setTimeout(() => console.log("2"), 0);
Promise.resolve().then(() => console.log("3"));
console.log("4");
// 1, 4, 3, 2
```

## 🛠️ Tool of the Day: Clinic.js

- **What:** Clinic.js is an open-source Node.js performance toolkit (from NearForm) with four tools: **Doctor** (diagnoses common performance problems), **Bubbleprof** (async I/O latency bubbles), **Flame** (CPU flamegraphs), and **HeapProfiler** (memory allocation flamegraphs). Home: https://clinicjs.org
- **Why it is useful:** When a server is slow, guessing is expensive. Clinic.js measures exactly what the event loop is doing — event-loop delay, CPU hotspots, async bottlenecks — and Doctor even recommends which deeper tool to reach for next.
- **Try it:** Install it and point it at your app, then generate some load:

```
npm install -g clinic
clinic doctor -- node server.js
```

Stop the server (Ctrl+C) and Clinic opens an HTML report with health checks and recommendations. For suspected I/O issues, follow up with `clinic bubbleprof -- node server.js`; for CPU hotspots, `clinic flame -- node server.js`.
