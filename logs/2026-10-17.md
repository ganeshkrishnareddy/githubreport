## 💡 Concept of the Day: Consistent Hashing — Sharding Without the Shuffle

**The one-line version:** When you add or remove a server, consistent hashing remaps only ~K/n keys instead of nearly all of them — the trick that lets caches and distributed stores scale without a meltdown.

**The idea:** The naive way to shard is `server = hash(key) % N`. It works fine until N changes — then nearly every key lands on a different server, every cache misses at once, and your database gets stampeded. Consistent hashing puts servers *and* keys on the same hash ring: each key belongs to the first server clockwise from it. Add or drop a server, and only the keys between it and its neighbor move — everything else stays put.

**Three things that matter in production:**
- **Virtual nodes (vnodes)** — give each physical server many points on the ring so keys spread evenly; a single random point per server can skew badly.
- **Scaling doesn't nuke your cache** — removing a node moves only its keys to the next node clockwise, so hit rates survive deploys and failures instead of collapsing.
- **It's everywhere** — Amazon's Dynamo paper (SOSP 2007) popularized it; Cassandra's partitioning, memcached clients, and CDNs all run on the same idea.

## 🛠️ Tool of the Day: DuckDB — SQLite for Analytics

**What it is:** DuckDB is an in-process analytical (OLAP) SQL database — "SQLite for analytics." No server to install, no daemon to babysit: it's a library and CLI with a columnar, vectorized engine that runs inside your process.

**Why it's useful:**
- Query CSV, Parquet, and JSON files *directly* with SQL — no import step: `SELECT * FROM 'sales.csv'`, `SELECT * FROM read_parquet('events/*.parquet')`, even over HTTPS
- Fast on data that chokes pandas — the columnar engine reads only the columns your query needs, with parallel execution
- Zero-copy Python integration — `SELECT * FROM my_dataframe` queries a pandas or Polars DataFrame in place, no conversion needed

**How to try it:**
```bash
pip install duckdb        # or: brew install duckdb
python3 -c "import duckdb; duckdb.sql(\"SELECT count(*) FROM 'sales.csv'\").show()"
```
Or open the CLI with `duckdb` and run `SELECT * FROM 'events.parquet' LIMIT 10;` — instant answers on files that would make a spreadsheet cry.
