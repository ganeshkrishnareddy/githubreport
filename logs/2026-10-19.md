## 💡 Concept of the Day: LSM Trees — Why Write-Heavy Databases Are So Fast

**The one-line version:** Log-Structured Merge trees flip the database write problem on its head — instead of updating data in place on disk, they buffer writes in memory and flush them as sorted, immutable files, making every write sequential and fast.

**The problem:** traditional B+ tree indexes update disk pages *in place*. When writes scatter across random pages, every write is a random disk I/O — tens of times slower than sequential writes — and the bottleneck gets worse as data grows.

**The LSM answer (Patrick O'Neil et al., 1996):**
- **Memtable** — every write goes first into an in-memory sorted structure (usually a skip list). A write is just a fast in-memory insert.
- **Write-ahead log (WAL)** — writes are appended to a log on disk first, so a crash loses nothing.
- **SSTable** — when the memtable fills up, it is frozen and flushed to disk as an immutable **Sorted String Table**. Never modified again.
- **Compaction** — a background process periodically merges SSTables, discarding overwritten and deleted entries (deletes are just "tombstone" markers), keeping read costs bounded.

**The trade-off:** writes become O(memory insert) fast, at the cost of reads checking multiple files (mitigated by Bloom filters and indexes) and background compaction work. It's why LSM engines power Google Bigtable, Apache Cassandra and HBase, and key-value stores like LevelDB and RocksDB — anywhere writes arrive in torrents.

## 🛠️ Tool of the Day: HTTPie — cURL for Humans

**What it is:** [HTTPie](https://pypi.org/project/httpie/0.9.5/) (`http`) is an open-source command-line HTTP client built to make interacting with web services from the terminal as human-friendly as possible. Created by Jakub Roztocil, it runs on Python under the hood.

**Why it's useful:**
- **Natural syntax** — `http GET httpbin.org/get name==Jane` instead of `curl -s -H ... | python3 -m json.tool`. `=` sends string data, `:=` sends numbers/booleans, `==` adds query params.
- **Colorized, formatted output** — JSON responses are pretty-printed and syntax-highlighted by default, a huge win when debugging APIs.
- **Handy extras** — built-in auth, file uploads (`--form file@./data.csv`), `--offline` to preview a request without sending it, and `--download` for wget-style fetches.

**How to try it:**
```bash
pip install httpie        # or: brew install httpie / apt install httpie
http GET httpbin.org/get name==Jane age==30
http POST httpbin.org/post name=Jane age:=30
```
