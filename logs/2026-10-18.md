## 💡 Concept of the Day: Backpressure — When Consumers Push Back

**The one-line version:** Backpressure is a feedback loop that lets a slow consumer signal a fast producer to slow down — so queues stay bounded instead of crashing your system.

**The problem:** a producer emits 10,000 events/sec into a queue, but the consumer can only process 1,000/sec. Without backpressure, the queue grows unbounded until memory is exhausted and the system falls over. Buffering alone isn't a fix — it just postpones the crash.

**How real systems push back:**
- **Bounded queues** — a full queue blocks the producer (`BlockingQueue.put()` in Java, bounded channels in Go) until there's room. The capacity limit *is* the signal.
- **Pull-based consumption** — Kafka consumers and Reactive Streams *ask* for data instead of receiving it, so the producer can never outrun the slowest consumer.
- **Load shedding** — when queues fill, drop or reject (HTTP 429/503) instead of queueing forever; the client learns the system's real capacity.

**Not backpressure:** plain retries (they amplify overload), autoscaling (too slow to react to a spike), and static rate limits (a fixed cap, not a dynamic capacity signal).

## 🛠️ Tool of the Day: ripgrep — grep, Rebuilt for Speed

**What it is:** [ripgrep](https://github.com/BurntSushi/ripgrep) (`rg`) is a line-oriented search tool written in Rust by Andrew Gallant (BurntSushi) — a drop-in replacement for `grep -r` tuned for searching code.

**Why it's useful:**
- **Fast** — benchmarks consistently beat `grep`, `ag`, and `ack` on large repos, thanks to Rust's regex engine and parallel directory traversal
- **Smart defaults** — respects `.gitignore`, skips hidden files and binaries, and colorizes output grouped by filename — all with zero flags
- **Modern regex** — Unicode-aware out of the box, with optional PCRE2 (`-P`)

**How to try it:**
```bash
# install
sudo apt install ripgrep   # Debian/Ubuntu
brew install ripgrep       # macOS

# recursive search — skips node_modules, .git, and binaries automatically
rg "TODO"

# everyday flags
rg -t py "import"              # only Python files
rg -l "fixme" | xargs grep -i urgent   # files with matches, piped onward
rg -uuu "secret"               # search everything: no ignores, hidden + binary files
```
