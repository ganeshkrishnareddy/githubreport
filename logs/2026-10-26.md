## 💡 Concept of the Day

### Semantic Versioning — read the version number like a contract

A version number like `2.4.1` is not just a label. Under Semantic Versioning (SemVer), its three parts are a promise about what changed:

- **MAJOR** (`2.x.x`) — incompatible API changes. Upgrading may break your code, so read the changelog first.
- **MINOR** (`x.4.x`) — new functionality added in a backwards-compatible way. Existing code keeps working.
- **PATCH** (`x.x.1`) — backwards-compatible bug fixes only. This is the safest upgrade.

Two extra rules make the contract work:

- When MAJOR goes up, MINOR and PATCH reset to zero (`1.9.3` → `2.0.0`). When MINOR goes up, PATCH resets to zero.
- A released version is never modified in place. Any change, even a tiny fix, gets a new version number.

The common mistake is bumping MAJOR for anything that feels "big". A full internal rewrite that does not change the public API is still a MINOR change; what matters is the impact on existing users, not the size of the work. And `0.y.z` versions carry no stability promise at all: anything may change at any time.

That is why package managers can automate safe upgrades: a dependency pinned to `^1.4.2` can take new MINOR and PATCH releases, but never a breaking MAJOR, without you asking for it.

## 🛠️ Tool of the Day

### tldr pages — man pages, minus the wall of text

[tldr pages](https://github.com/tldr-pages/tldr) is a community-maintained collection of simplified, example-first help pages for command-line tools, meant as a complement to traditional man pages. Instead of every flag a tool supports, you get the handful of examples people actually use.

Why it is useful:

- Learn a command's common usage in seconds, e.g. how to extract a tar archive, without reading a full manual.
- Pages cover Linux, macOS, Windows, and more, and each page links back to its source so you can suggest fixes.
- It pairs well with man pages: tldr for "how do I do this?", man for "what does every option do?"

How to try it:

```bash
pipx install tldr
# or: brew install tldr
tldr tar
tldr git checkout
```

No install needed either: browse the same pages in your browser at the web client linked from the project README.
