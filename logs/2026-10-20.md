## 💡 Concept of the Day: CORS — Why Your Browser Blocks Your Own API Call

**The one-line version:** CORS (Cross-Origin Resource Sharing) is the browser's permission-slip system — a server opts in, via response headers, to letting *other* websites' JavaScript read its responses.

**Why the restriction exists:** the same-origin policy stops a script on one site from reading responses from another. Without it, a malicious page could silently fetch your logged-in banking data — your cookies travel with the request, and the script would read the result.

**Simple vs preflighted requests:**
- **Simple** (basic GET/POST with safe headers) goes straight through; the response just needs `Access-Control-Allow-Origin` for the browser to hand it to your script.
- **Non-simple** (PUT/DELETE, custom headers, JSON bodies) triggers an automatic `OPTIONS` **preflight** first. The server answers with `Access-Control-Allow-Methods` / `Access-Control-Allow-Headers`, and only then does the real request fire.

**Three things people get wrong:**
1. `Access-Control-Allow-Origin: *` **with credentials is rejected** — when `Access-Control-Allow-Credentials: true`, you must echo the exact origin, never `*`.
2. CORS is enforced by the **browser**, not the server — `curl` and Postman never hit it. "Works in Postman" proves nothing.
3. The fix is always server-side headers (or a same-origin proxy) — no client-side trick bypasses it.

## 🛠️ Tool of the Day: fzf — Fuzzy-Find Everything from the Terminal

**What it is:** [fzf](https://github.com/junegunn/fzf) is a general-purpose command-line fuzzy finder by Jun Ki Ahn — an interactive filter that reads any list from stdin, lets you fuzzy-search it, and prints your selection to stdout. Single binary, no dependencies, ships with shell integrations.

**Why it's useful:**
- **Ctrl+R** — fuzzy-search your command history instead of retyping long commands
- **Ctrl+T** — fuzzy-pick files for any command (`vim $(fzf)`); **Alt+C** — fuzzy `cd` into directories
- **Pipe anything through it** — `git log --oneline | fzf`, `ps aux | fzf` to find a runaway process, `history | fzf` — it turns any list into an interactive menu

**How to try it:**
```bash
brew install fzf            # macOS, then run $(brew --prefix)/opt/fzf/install
sudo apt install fzf        # Debian/Ubuntu
git clone --depth 1 https://github.com/junegunn/fzf.git ~/.fzf && ~/.fzf/install
```
