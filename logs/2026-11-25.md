## 💡 Concept of the Day

### HTTP/3 & QUIC — the web’s faster, tougher transport

Every page you load today probably travels over HTTP/2, which runs on TCP — a protocol designed in the 1970s. **HTTP/3** swaps the foundation: it runs on **QUIC**, a modern transport protocol built on UDP, and that one change fixes several problems TCP could never shake off.

The biggest fix is **head-of-line blocking**. With HTTP/2 over TCP, one lost packet stalls *every* stream sharing the connection, because TCP delivers bytes strictly in order. QUIC gives each stream its own lane: a lost packet delays only the stream it belongs to, while the rest keep flowing. On lossy mobile networks, that difference is felt immediately.

Two more upgrades worth remembering:

- **Faster handshakes.** QUIC folds the TLS 1.3 handshake into the transport handshake, so a first connection takes one round trip instead of two or three. Repeat visits can even use **0-RTT**, sending data with the very first packet.
- **Connection migration.** QUIC identifies a connection by an ID, not by IP address and port. Switch your phone from Wi-Fi to mobile data mid-download and the same connection survives — no re-handshake, no dropped video call.

Encryption is also baked in by default: QUIC encrypts nearly everything, including most handshake data, so middleboxes cannot inspect or tamper with it the way they could with TCP. All major browsers support HTTP/3 today, and most CDNs serve it with a toggle — you can check your own site in Chrome DevTools by enabling the Protocol column and looking for `h3`.

## 🛠️ Tool of the Day

### jq — a Swiss Army knife for JSON on the command line

**jq** is a lightweight command-line JSON processor. Feed it JSON from an API response, a log file, or a config, and it can filter, reshape, and extract exactly the fields you need — no throwaway Python script required.

Why it is useful: APIs return huge JSON blobs, and `jq` lets you slice them in one pipeline. It pretty-prints, sorts keys, selects nested values, and can even build new JSON from old. Once it is in your muscle memory, debugging APIs and wrangling data files gets much faster.

Try it:

```bash
# Install (Debian/Ubuntu)
sudo apt install jq

# Pretty-print an API response and pick one field
curl -s https://api.github.com/repos/jqlang/jq | jq .stargazers_count

# List the names of every repo in a JSON array
jq -r ".[].name" repos.json

# Filter objects and reshape them
jq ".[] | select(.language == \"Python\") | {name, stars: .stargazers_count}" repos.json
```
