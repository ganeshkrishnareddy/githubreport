## 💡 Concept of the Day: Idempotency Keys

**The one-line version:** An idempotency key is a unique token the client sends with a request so that if the request is retried (after a timeout, crash, or network blip), the server runs the operation only once instead of charging you twice.

**How it works:**
- The client generates a unique key per *logical* operation (typically a UUID v4) and sends it in the `Idempotency-Key` header on `POST`/`PATCH` requests.
- Before executing, the server looks up the key in a durable store (a DB table or Redis). Miss → execute inside a transaction that also stores the key with the full response. Hit → replay the stored response verbatim, without re-executing.
- Same key + different request body means the client is misusing the key → reject it (Stripe returns an error; the IETF draft recommends `422`).

**Why it matters:** A client can time out *after* the server already processed the request. Without idempotency, timeout + automatic retry = a double charge, a duplicate order, two welcome emails. Exactly-once *delivery* is impossible in a distributed system, but exactly-once *effect* is just at-least-once delivery plus idempotent processing.

**In the wild:** Stripe, PayPal, and Adyen all accept the `Idempotency-Key` header; Stripe stores the (key → response) mapping for 24 hours. The IETF is formalizing the pattern in `draft-ietf-httpapi-idempotency-key-header`.

## 🛠️ Tool of the Day: uv

- **What:** uv is an extremely fast Python package and project manager written in Rust by Astral (the creators of Ruff). A single tool replaces pip, pip-tools, pipx, poetry, pyenv, twine, and virtualenv. Home: https://github.com/astral-sh/uv
- **Why it is useful:** It resolves and installs packages far faster than pip (Astral benchmarks 10-100x), manages Python versions itself, and brings Cargo-style project management with a universal lockfile. It also ships a pip-compatible interface, so you get the speed boost with a CLI you already know.
- **Try it:** Install it (no Rust or Python needed first), then spin up a project:

```
curl -LsSf https://astral.sh/uv/install.sh | sh   # macOS / Linux
uv init hello
cd hello
uv add requests
uv run hello.py
```
