## 💡 Concept of the Day

### Feature Flags — ship code without shipping risk

A feature flag (also called a feature toggle) is a switch in your code that turns a feature on or off without a new deploy. It separates *deployment* from *release*: you can merge code to production, keep it hidden, and reveal it only when you are ready.

```python
if feature_enabled("new-checkout"):
    show_new_checkout()
else:
    show_old_checkout()
```

That one switch unlocks several useful patterns:

- **Gradual rollouts** — enable a feature for 1%, then 10%, then everyone, watching errors at each step.
- **Kill switches** — if a release misbehaves, turn it off in seconds instead of rolling back a deploy.
- **Targeted releases** — enable it for internal users, beta testers, or one region first.
- **Experiments** — show variant A to some users and variant B to others, and measure the difference.

The trap is flag debt. Every flag adds a code path to test and reason about. Give each flag a clear name and owner, remove it once the rollout is done, and prefer breaking a feature into small, safe pieces over hiding a huge change behind a flag forever.

## 🛠️ Tool of the Day

### Unleash — open-source feature flags you can self-host

Unleash is an open-source feature flag platform. You define flags in its dashboard, then check them from your app with an SDK. Flags can have different settings per environment, and activation strategies such as gradual rollout, specific user IDs, IPs, or hostnames.

How to try it:

1. Follow the getting-started guide to run Unleash locally with Docker.
2. Create a flag, for example `new-checkout`, in the dashboard.
3. Connect your app with an SDK for your language and wrap the new code in an `isEnabled("new-checkout")` check.
4. Flip the flag on for a small group first, then widen the rollout.

Why it is useful: you get the core flag workflow (dashboard, strategies, SDKs) without paying for a hosted service or building your own flag system, and your app code depends on simple on/off checks rather than deploy timing.
