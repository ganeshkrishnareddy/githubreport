## 💡 Concept of the Day

### Git Worktrees — one repo, many working copies

You are deep in a feature branch with uncommitted changes when an urgent hotfix lands. The usual dance: stash everything, switch branches, fix, switch back, pop the stash, and hope nothing conflicts. There is a cleaner way built into Git itself.

`git worktree` lets one repository have several working trees at once, each checked out to a different branch. They share the same `.git` data, so no second clone and no re-downloading history:

```bash
git worktree add ../hotfix hotfix-branch
cd ../hotfix
# fix, commit, push — your feature branch stays untouched
git worktree remove ../hotfix
```

Why it is worth knowing:

- **No stash juggling.** Each worktree has its own working tree and index, so half-finished work never gets in the way of urgent work.
- **Run things in parallel.** Keep the app running from one worktree while you test a risky change in another, or compare two branches side by side.
- **Cheap.** A linked worktree reuses the repo's objects; only the checked-out files are duplicated.

Two gotchas to remember: the same branch cannot be checked out in two worktrees at once, and a worktree deleted by hand (instead of `git worktree remove`) leaves stale metadata behind — clean it up with `git worktree prune`.

## 🛠️ Tool of the Day

### fzf — a fuzzy finder for the terminal

[fzf](https://github.com/junegunn/fzf) is a general-purpose command-line fuzzy finder: feed it any list of lines, and it opens an interactive prompt where you type a few fuzzy characters and it narrows the list in real time. The selection is printed back to stdout, so it composes with everything else in your shell.

Why it is useful:

- **Find files without remembering paths.** Type fragments of a filename, even out of order, and still land on the right one.
- **It is a filter, not just a file finder.** Pipe in git branches, process lists, shell history, or command output — fzf filters whatever you give it.
- **Preview as you browse.** A preview window shows the file or commit under the cursor, so you pick with confidence instead of guessing.
- **Shell integration.** Once set up, it upgrades Ctrl-R history search and file completion in bash, zsh, and fish.

How to try it:

```bash
brew install fzf        # macOS
# or: sudo apt install fzf   # Ubuntu/Debian
vim $(fzf)              # pick a file and open it
git branch | fzf         # pick a branch interactively
history | fzf           # find that command you ran last week
```

Pair it with tools from earlier logs: `git ls-files | fzf` to jump to any tracked file, or pipe ripgrep results through it to browse matches interactively.
