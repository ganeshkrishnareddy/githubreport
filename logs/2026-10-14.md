## 💡 Concept of the Day: RAG — Let the Model Read Before It Speaks

**The one-line version:** Retrieval-Augmented Generation makes an LLM look up the facts it needs *before* answering — an open-book exam instead of a closed-book one.

**The idea:** An LLM only knows what it learned during training. Hand it your private docs, today's data, or your company's policies and it will guess. RAG flips the order: **Retrieve** (search your knowledge base for relevant passages), **Augment** (paste those passages into the prompt as context), **Generate** (let the model answer using them). The model's weights never change — only the context does, so updating your documents updates the answers with no retraining.

**Three things that matter in production:**
- **Chunking decides quality** — big documents get split into chunks before embedding. Too big and the model drowns in noise; too small and meaning gets sliced in half. Overlapping chunk boundaries is the usual cheap fix.
- **RAG closes three classic gaps** — stale knowledge (the model stopped learning at its training cutoff), private data (it never saw your docs), and hallucination (answers stay grounded in real passages).
- **Evaluate retrieval, not just answers** — if the wrong chunks were retrieved, no prompt trick will save the answer. Log the retrieved chunks and inspect them first when answers go wrong.

## 🛠️ Tool of the Day: ChromaDB — a Vector Database That Lives in Your Python Process

**What it is:** ChromaDB is an open-source embedding database: store text chunks plus their vectors, then run semantic search with a few lines of Python. No server, no API keys — `pip install chromadb` and it runs in-process. [trychroma.com](https://www.trychroma.com)

**Why it's useful:**
- It's the fastest path from "I have some documents" to a working RAG retrieval layer — ideal for prototypes and side projects
- The persistent client saves the index to disk, so you build once and query across restarts
- Metadata filters (e.g. `{"source": "handbook"}`) let you scope retrieval to the right subset of documents

**How to try it:**
```python
import chromadb

# persistent client — the index survives restarts
client = chromadb.PersistentClient(path="./chroma_db")
docs = client.get_or_create_collection(name="my_docs")

docs.add(
    documents=["RAG retrieves relevant passages before the LLM answers"],
    ids=["doc1"],
    metadatas=[{"source": "daily-log"}],
)

results = docs.query(query_texts=["How does RAG work?"], n_results=2)
print(results["documents"][0])
```
